# TPI - Sistema de Gestión "Café Salta"

## Descripción del Sistema
Sistema integral de gestión para la cafetería "Café Salta", modelado mediante procesos BPMN para optimizar la atención al cliente en dos modalidades: atención al paso (mostrador) y atención en mesa, integrando control de inventario de stock y validación de facturación.

## Transparencia y Declaración de IA
Para la elaboración del presente trabajo se utilizó Gemini como herramienta de apoyo para la organización y revisión de contenidos. Asimismo, se utilizó Claude para generar el gráfico BPMN. El contenido y los resultados obtenidos fueron revisados y adaptados por el estudiante, quien asume la responsabilidad por la coherencia y exactitud conceptual de la entrega.
### Correcciones principales aplicadas al modelo inicial (Claude):
* **Reorganización de Lanes:** Se reestructuraron los carriles (*Lanes*) para que coincidan de manera exacta con los roles definidos en el organigrama institucional.
* **Modelado de Subprocesos:** Se bifurcó el flujo general para considerar de forma independiente los dos subprocesos posibles según la modalidad de atención (*Cliente al Paso* vs. *Cliente de Salón*).
